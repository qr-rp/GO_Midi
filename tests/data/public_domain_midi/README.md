# Public-domain MIDI benchmark files

These are unmodified MIDI bytes downloaded from
[`tactilegalactic/public-domain-midi`](https://github.com/tactilegalactic/public-domain-midi),
which records per-file provenance and licensing evidence.

Dataset repository license and notices are preserved in `LICENSE`, `NOTICE`,
and `PROVENANCE.md`. Each MIDI retains its own source-specific Public Domain
or CC0 status. These files are test fixtures and are not required at runtime.
